Saturday night. A week ago, I didn't/ˈdɪdnt/ know/nəʊ/ anyone in/ɪn/ this/ðɪs/ city. Now I have/hæv/ two friends here. I'm happy to write about them. I'm still not sure if this flat is right for/fɔː/ me. But I'm sure that/ðæt/ I like/laɪk/ this street.
星期六晚上。一个星期前，我在这座城市谁也不认识。现在我在这儿有了两个朋友。我很高兴写写他们。我还说不准这套公寓适不适合我，可我敢肯定，我喜欢这条街。
On my first morning, Tom asked, "Are you new here?" He lives next door. He is responsible for the building. I was too shy to say/seɪ/ much that day. I wish I were more like him. He is always happy to help.
搬来的第一个早上，汤姆问我：「你是新搬来的吗？」他住在隔壁，这栋楼也归他管。那天我害羞得没说几句话。真希望我能更像他一点。他总是很乐意帮忙。
On/ɒn/ Sunday, I met Tom's sister Anna at the café. She was late, but she was so/səʊ/ funny! On Monday, I lost my key. "I'm sorry to ask for help again," I said/sed/. Tom just/dʒʌst/ smiled and got/ɡɒt/ me a spare key. "Are you too tired to cook? I'm going to make some tea."
星期天，我在咖啡馆认识了汤姆的妹妹安娜。她迟到了，可她特别有趣！星期一，我把钥匙弄丢了。「不好意思，又要找你帮忙了。」我说。汤姆只是笑了笑，给我拿来一把备用钥匙。「你是不是累得做不动饭了？我去泡点茶。」
Work is hard. I have to learn new things, such as the doctors' names. There are forty doctors. I know only five of them! Sometimes I'm afraid that I'm too slow. But I'm sure that I can do/duː/ this job. Tom asked, "Are you sure that you're not/nɒt/ just tired?" Well/wel/, I think/θɪŋk/ he is right.
工作很难。我得学新东西，比如医生们的名字。医生有四十个，我只认识五个！有时候我怕自己太慢了，但我确定自己能做好这份工作。汤姆问：「你确定你不只是累了？」嗯，我觉得他说得对。

我平时可害羞了。我这是怎么了？我也说不清，可我喜欢现在这样。我很高兴有人帮忙，明天安娜也会在那里。我敢肯定，下周会顺利一些。我不怕星期一了。好吧，也许还有一点点。

难句拆解：7 句

先找骨架，再看它后面多加了什么：不定式、从句，还是虚拟
I'm happy to write about them.骨架 + 不定式我很高兴写写他们。
先找骨架：I'm happy（我很高兴）。只加 to write about them，说明高兴做什么；to 后接动词原形。
I'm happy to help.（我很乐意帮忙。）
I'm sorry to ask for help again.（第 3 段）
I'm ready to go.（第 5 段）
⚠️ to 后面用动词原形：✗ I'm happy to wrote → ✓ I'm happy to write。
I'm still not sure if this flat is right for me.骨架 + if 从句我还说不准这套公寓适不适合我。
骨架是 I'm not sure（我不确定），后面加 if + 一句话，说不确定的是什么。
I'm not sure if he is at home.（我不确定他在不在家。）
I'm not sure if I can come tomorrow.（我不确定明天能不能来。）
⚠️ if 后面那句话用陈述语序，主语在前：✗ if is this flat right → ✓ if this flat is right。
But I'm sure that I like this street.骨架 + that 从句可我敢肯定，我喜欢这条街。
骨架是 I'm sure（我肯定），后面加 that + 一句话，说肯定的是什么。
Sometimes I'm afraid that I'm too slow.（第 4 段）
Are you sure that you're not just tired?（第 4 段）
I'm sure next week will go well.（第 6 段，that 省掉了）
⚠️ sure、afraid、sorry 这类词后面的 that 可以省，意思不变：I'm sure (that) …
Are you too tired to cook?疑问骨架 + too … to你是不是累得做不动饭了？
骨架是 Are you tired?（你累吗？），加 too … to + 动词原形：太累了，做不了某件事。
I was too shy to say much that day.（第 2 段）
I'm too tired to cook.（我累得做不了饭。）
⚠️ too … to 本身就是「做不了」的意思：I'm too tired to cook 里没有 not，意思已经是「做不了饭」。
I wish I were more like him.骨架 + 虚拟（I wish）真希望我能更像他一点。
原来的骨架是 I'm like him（我像他）。这里先加 I wish 表示愿望，再把 am 换成 were：I wish I were like him。这不是普通的过去时间。
I wish I were braver.（要是我胆子大一点就好了。）
I wish I were at home now.（要是我现在在家就好了。）
⚠️ 这里练愿望句 I wish I were …。口语中也能听到 I wish I was …；本组回忆题按原句用 were。
If I were still in my old city, I'd be alone this Sunday.骨架 + 虚拟（If I were …, I'd be …）要是我还在原来的城市，这个星期天我就只能一个人过了。
骨架是 I'm alone（我一个人）。说不是真的情况：这半句换成 I'd be alone（I'd = I would），前面加 If I were … 说假设。
If I were you, I'd be happy.（要是我是你，我会很开心。）
If I were at home, I'd be in bed now.（要是我在家，现在早躺床上了。）
⚠️ 这一句是假设现在的情况：if 半句用 were，结果半句用 would / 'd + be。不要把这里的规则套到所有 if 句上。
Would you be OK if we met at nine?疑问骨架 + 虚拟我们九点见，你看行吗？
从 Are you OK?（你觉得可以吗？）出发，换成 Would you be OK，再加 if we met at nine。整句是在试探一个安排，不是说过去见过面。
Are you OK?（直接问）
Would you be happy if I came too?（我也去的话，你会高兴吗？）
⚠️ 这里 met 虽然是过去式，却在假设明天九点见面。Would you be OK if …? 可以用来委婉询问，不一定表示「不可能」。

换成你自己的事

每题说一句，说出声；卡住了再看参考
1. 用 I'm happy to … 或 I'm ready to …，说一件你乐意做、或者准备好要做的事。
看参考说法
I'm happy to help my friends. I'm ready to start my new job.
2. 用 I'm sure that … 和 I'm not sure if …，各说一件你确定的事和拿不准的事。
看参考说法
I'm sure that I like my job. I'm not sure if I can finish it today.
3. 用 I wish I were … 或 If I were …, I'd be …，说一个现在做不到的愿望。
看参考说法
I wish I were at the beach now. If I were there, I'd be so happy.
4. 用 Are you … to …? 或 Would you be OK if …?，约朋友做一件事。
看参考说法
Are you free to have lunch tomorrow? Would you be OK if we met at twelve?
