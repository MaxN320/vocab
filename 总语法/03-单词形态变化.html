单词变化

English inflection · nouns · verbs · adjectives & adverbs

这份笔记只管一件事：同一个英语单词，为了适应语法位置，词形怎么变化。主干只有三套：名词的数、动词的形态、形容词/副词的比较等级。

母逻辑：先判断“语法要什么形态” → 再判断“词干需不需要调整” → 最后加词尾；发音则优先看最后一个“音”，不是最后一个字母。 很多看似分散的规则其实是重复出现的：辅音+y、静音e、重读短元音+单辅音、-s/-ed 发音。

先看五个会反复出现的词干处理规则 shared spelling logic

为什么先学
如果把每个章节分开背，你会重复背很多次。其实英语词形变化反复调用的就是下面几种“词干处理程序”。
真正重点
看清楚哪些规则跨系统复用，以及哪些看起来相似却不能乱套。
① 默认：直接加词尾
词干没有冲突时，直接接后缀。
book→books · work→worked · work→working · tall→taller
② 辅音字母 + y
在 -s / -ed / -er / -est 前通常 y→i；但 -ing 前不变 i。
baby→babies · study→studied · happy→happier · study→studying
③ 不发音 e
不同后缀处理不同：-ed 只 +d；-ing 常去 e；-er/-est 只 +r/+st。
move→moved · make→making · nice→nicer→nicest
④ 重读短元音 + 单辅音
在某些后缀前需要双写末辅音，目的是保住前面的短元音。
stop→stopped / stopping · big→bigger / biggest
⑤ c 结尾
接 -ed / -ing 时常补 k，保持 /k/。
panic→panicked · panicking · mimic→mimicked · mimicking
最容易串错的一条：“辅音+y → i”不是万能规则。study → studied / studies，但必须是 study → studying，不是 studiing。
📍 压缩：先别背“名词一套、动词一套、形容词一套”。先认出词干是否属于 y / e / CVC / c 这几个高频入口。
1

名词可数名词：单数 → 复数 noun plural

核心
规则复数本质是给名词接 -s / -es；特殊拼写只是为了让词更容易读、保持原来的发音。
发音
最终 -s / -es 怎么读，要看单数词最后一个音，不是看最后一个字母。

拼写规则

默认 +s
book→books · car→cars · dog→dogs
s / x / z / sh / ch → +es
bus→buses · box→boxes · buzz→buzzes · wash→washes · watch→watches
辅音字母 + y
y→i + es。
baby→babies · city→cities · story→stories
f / fe
不稳定：一部分 → ves，一部分直接 +s，不能靠一个规则全推。
life→lives · knife→knives · leaf→leaves ｜ roof→roofs · belief→beliefs
o 结尾
也不稳定，记高频词。
tomato→tomatoes · potato→potatoes · hero→heroes ｜ photo→photos · piano→pianos · video→videos
不规则 · 换元音
词尾不加东西，改中间的音。
man→men · woman→women · tooth→teeth · foot→feet · goose→geese · mouse→mice
不规则 · 加 -en
极少数，就这两个。
child→children · ox→oxen
不规则 · 换词
复数是另一个词。
person→people
-man 结尾的复合词
跟着 man 走，不是加 s。
policeman→policemen · postman→postmen · Englishman→Englishmen
单复数同形
一个字母都不加。
sheep · deer · fish · moose · aircraft · means · series · species · Chinese · Japanese
外来词
拉丁 / 希腊来源，阅读里高频。-is→-es 最成系统。
analysis→analyses · basis→bases · crisis→crises · thesis→theses ｜ phenomenon→phenomena · criterion→criteria ｜ datum→data · medium→media · bacterium→bacteria
只有复数形
没有单数；要论个数用 a pair of。
glasses · scissors · trousers · jeans · shorts · clothes

-s / -es 发音

/ɪz/
咝音结尾：/s z ʃ ʒ tʃ dʒ/
buses · boxes · washes · pages
/s/
其他清辅音结尾
cats · books · cups
/z/
元音 / 其他浊辅音结尾
dogs · beds · boys · keys
认知修正：上面从「不规则」往下的几类不归拼写规则管，它们是封闭清单，看见就调取记忆，别拿 +s / +es 去推。规则那几条负责的是"这词没被点名"的情况。
📍 压缩：拼写看字母结构；发音看最后一个音。-s 的 /s z ɪz/ 这一套，后面三单会原样复用。
2

动词 A第三人称单数 V → V-s / V-es

核心
一般现在时里，主语是 he / she / it / 单数名词时，实义动词通常进入三单形式。
共享系统
三单和名词复数的 -s / -es 拼写与发音逻辑高度相似，不用重新学一套。
默认 +s
work→works · read→reads · like→likes
s / ss / x / z / sh / ch → +es
pass→passes · fix→fixes · buzz→buzzes · wash→washes · watch→watches
辅音字母 + y
y→i + es。
study→studies · try→tries · carry→carries
元音字母 + y
直接 +s。
play→plays · enjoy→enjoys · buy→buys
高频 o 结尾
do / go 用 -es；不要把“辅音+o 一律 +es”当成普遍规则。
do→does · go→goes
特殊
have→has · be→is

发音：直接复用名词复数

/ɪz/
咝音结尾
passes · washes · watches
/s/
其他清辅音结尾
works · likes
/z/
元音 / 其他浊辅音结尾
reads · plays · goes
单独记：has、does、is 的读音不要拿常规拼写硬推。
📍 压缩：三单 = “名词复数那套 -s 系统”搬到动词上，再额外记 have→has、do→does、be→is。
3

动词 B过去式 + 过去分词 V2 / V3

先分身份
过去式 V2 和 过去分词 V3 是两种不同语法形态；只是规则动词恰好同形。
母逻辑
规则动词：V2 = V3，统一走 -ed 系统；不规则动词：第三列单独记。

规则动词拼写

默认 +ed
answer→answered · look→looked · play→played
不发音 e → +d
arrive→arrived · move→moved · use→used
辅音字母 + y
y→i + ed。
study→studied · try→tried · carry→carried
元音字母 + y
直接 +ed。
play→played · enjoy→enjoyed
重读短元音 + 单辅音
双写末辅音 + ed。
stop→stopped · plan→planned · prefer→preferred
c → cked
panic→panicked · mimic→mimicked
双写别只记“重读闭音节”四个字。更稳的判断是：最后一个音节重读 + 短元音 + 单辅音结尾。而 w / x / y 通常不双写：snowed / fixed / played。

-ed 发音

/ɪd/
原动词最后一个音是 /t/ 或 /d/
wanted · needed
/t/
其他清辅音结尾
looked · washed · watched · stopped
/d/
元音 / 其他浊辅音结尾
played · answered · moved · called

不规则动词：按三列关系压缩

AAA
V1 = V2 = V3
cut→cut→cut · put→put→put · hit→hit→hit
ABB
V2 = V3
buy→bought→bought · make→made→made · leave→left→left · say→said→said
ABA
V1 = V3
come→came→come · run→ran→run · become→became→become
ABC
三种形式不同
write→wrote→written · see→saw→seen · take→took→taken · give→gave→given
高频特殊
be→was/were→been · do→did→done · go→went→gone
认知修正：不要记“过去分词 = 过去式”。应该记：规则动词的过去式和过去分词同形；不规则动词未必同形。
📍 压缩：规则 V2/V3 共用一套 -ed；不规则只额外记第三列。
4

动词 C现在分词 V-ing stem + ing

母逻辑
V-ing = 词干处理 + ing。真正要判断的不是“怎么加 ing”，而是加之前词干是否要变。
用途
进行时、动名词、分词结构都会调用这一形态。
默认 +ing
work→working · read→reading · play→playing
不发音 e → 去 e
make→making · write→writing · take→taking · use→using
ie → y + ing
lie→lying · die→dying · tie→tying
重读短元音 + 单辅音
双写末辅音 + ing。
run→running · sit→sitting · stop→stopping · begin→beginning · admit→admitting
c → ck + ing
panic→panicking · mimic→mimicking
e 结尾不是见 e 就删：see→seeing、agree→agreeing；be→being。另外 dye→dyeing 保留 e，是为了和 die→dying 区分。
英美差异：部分以 l 结尾的双音节词，英式英语更常双写 l：travelling；美式常写 traveling。两种都要能认。

发音

/ɪŋ/
标准 -ing 结尾基本固定
working · reading · singing
/ŋ/
一个鼻音，不是 /n/ + /g/ 两个音
sing /sɪŋ/
-in'
非正式口语可弱化为 /ɪn/；标准学习仍按 /ɪŋ/
workin'
📍 压缩：ie→y；静音 e→去 e；重读短元音+单辅音→双写；c→ck；其他直接 +ing。
5

形容词 & 副词比较级与最高级 comparative / superlative

母逻辑
比较有两套实现方式：词内变化 -er / -est，或者词外加 more / most。词越短越倾向词内变化，词越长越倾向词外变化。
关键灰区
双音节不能一刀切。它正好处在两套系统之间，有些词用 -er/-est，有些 more/most，有些两种都自然。

-er / -est 拼写

默认 +er / +est
常见于单音节和部分双音节。
tall→taller→tallest · small→smaller→smallest · fast→faster→fastest
不发音 e
只 +r / +st。
nice→nicer→nicest · large→larger→largest
重读短元音 + 单辅音
双写末辅音。
big→bigger→biggest · hot→hotter→hottest · thin→thinner→thinnest
辅音字母 + y
y→i + er / est。
happy→happier→happiest · easy→easier→easiest · early→earlier→earliest

-er/-est 还是 more/most？

单音节
通常 -er / -est。
tall→taller→tallest · hard→harder→hardest
双音节
灰色地带。-y 结尾通常用 -er/-est；部分 -ow / -er / -le 结尾也常这样；另一些词更自然用 more/most；部分两种皆可。
happy→happier · narrow→narrower · clever→cleverer / more clever · simple→simpler / more simple
三音节及以上
通常 more / most。
beautiful→more beautiful→most beautiful · important→more important→most important
-ly 副词
通常 more / most。
carefully→more carefully→most carefully · slowly→more slowly→most slowly
短副词 / 平副词
常直接 -er / -est。
fast→faster→fastest · hard→harder→hardest · early→earlier→earliest
less / least 是另一条轴：它们不是“长单词专用规则”，而是表达较不…… / 最不……。less important / least important / less carefully / least carefully。

不规则变化

good / well
better → best
bad / badly / ill
worse → worst
many / much
more → most
little
表示“少量”时。
less → least
far
farther / further → farthest / furthest

“没有比较级”的词：不要记成绝对禁令

更准确的概念叫“不可分级形容词（non-gradable adjectives）”。有些词在中性字面义里表达近似绝对状态，例如 dead / impossible / perfect / unique / complete，通常不自然地拿来比较“更……”。
中性表达
常用 absolutely / completely / totally 等加强，而不是 very。
absolutely impossible · completely dead · absolutely perfect
真实英语边界
语境可以把“绝对概念”重新理解成有程度，因此 more perfect / more unique 等并非语法上绝对不存在，只是学习阶段不建议把它们当默认写法。
认知修正：“双音节及以上 = more/most”太粗；“大部分副词 = more/most”也太粗。更稳的是：多音节形容词和 -ly 副词通常 more/most；短词通常 -er/-est；双音节是灰区。
📍 压缩：短词偏 -er/-est；长词偏 more/most；双音节灰区；-ly 副词通常 more/most；不规则单独记。

最终判断流程

Q1
这个词是什么词类？
名词 → 看单复数｜动词 → 看三单/过去/V-ing/V3｜形容词/副词 → 看比较等级
Q2
语法要求哪一种形态？
先定“目标形态”，不要一看词就开始变形。
Q3
词干需不需要处理？
重点检查：辅音+y｜静音 e｜重读短元音+单辅音｜c 结尾。
Q4
规则变化还是不规则变化？
不规则名词 / 不规则动词 / 不规则比较级 → 单独记高频词。
Q5
词尾怎么读？
-s / -ed → 看原词最后一个音；-ing → 基本固定 /ɪŋ/。
整份笔记最后只需要记住一句：
英语的“单词变化”不是几十套独立规则，而是几个高频词干处理程序 + 几个语法词尾不断组合。

名词主要调用 -s；动词调用 -s / -ed / -ing / 不规则第三列；形容词和副词调用 -er/-est 或 more/most。
真正值得形成自动化的是：先确定目标形态 → 检查词干 → 加后缀 → 处理发音。
