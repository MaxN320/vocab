现在完成进行时 · 阶梯式笔记

它不是"一个时态",是现在 + 完成 + 进行 三块拼起来的。把三块拆开,再合回去,整个结构就通了。

1

地基:它不是"一个时态",是三层叠加

是什么 · 一个最本质的点
要解决:为什么它的名字里同时有"现在""完成""进行",却还能是一个整体? 为什么需要:大多数人把它当成一个"新的、要死记的时态"。其实它只是把三个已经学过的模块拼在一起,每一块管一件事。

把它拆开看:

现在→have / has把参考点钉在此刻
完成→been建立"更早 ↔ 参照点"的连接
进行→doing把事件打开成过程

三个模块各管一个维度:现在管"参考点在哪",完成管"时间关系",进行管"观察方式"。三块各司其职,拼在一起才叫"现在完成进行时"。

它和前面几课是一个系统:一般现在时看"现在的常态",现在进行时看"此刻正在展开的过程",现在完成时看"过去如何连接到现在",现在完成进行时看"这段连接里,过程是怎么一路走过来的"。

小结:不要把它当成一个新时态记。它是三个老模块的组合——现在给锚点、完成给关系、进行给过程。
2

解剖三块:每一块给什么,去掉它会变成什么

怎么理解 · 三模块各自的贡献
要解决:这三块具体各贡献什么?少了任何一块会怎样? 上一阶的局限:地基只说"有三块",没说"去掉一块会变成什么"。

"进行"给什么:把事件打开,看内部

进行模块的活儿是——把事件当成一个正在展开的过程,而不是一个已经完成的点。有没有它,决定你"看结果"还是"看过程"。

I have read the book.
书读完了。
没有"进行" → 看到的是结果 / 完成
I have been reading the book.
一直在读,可能还没读完。
加了"进行" → 看到的是过程 / 持续

"完成"给什么:建立"更早 ↔ 参照点"的连接

完成模块的活儿是——把一个更早的事件,和参照点挂上钩。有没有它,决定你"只看此刻"还是"从过去一路看过来"。

I am reading the book.
我正在读这本书。
没有"完成" → 只看此刻正在发生,不管之前多久
I have been reading the book.
我一直在读这本书。
加了"完成" → 从过去一路连接到现在

"现在"给什么:把参考点钉在此刻

现在模块的活儿是——决定参考点在哪。它用 have / has 把参照点定在"说话这一刻",换掉它,整套时态就换锚点。

have been doing→参照点 = 现在现在完成进行时
had been doing→参照点 = 过去过去完成进行时
will have been doing→参照点 = 将来将来完成进行时

三块里最"重"的是哪块?——现在这块。最左边的 have / has 承担了时态信息,改它,整套时态跟着变;后面两块的形式基本不动。

小结:去掉"进行" → 只看结果;去掉"完成" → 只看此刻;换掉"现在" → 换成另一个锚点。三块都在,才同时具备"连接 + 过程 + 现在"三个特点。
3

形式:三块怎么拼成 have been doing

怎么用 · 造句的骨架
要解决:知道三块各给什么了,它们具体怎么拼? 上一阶的局限:解剖说清"每块给什么",但形式为什么长这样、能不能换别的,还没落地。

公式一条:have / has + been + doing。它不是随便拼的,是一条严格的控制链:

have / has→后面要过去分词完成结构规定
be→been只能变成 been,不能是 being
been→后面要现在分词进行结构规定
do→doing动词打开成过程

为什么是 been,不是 being?

这是最常见的错误。being 是 be 的现在分词,它出现在进行结构里(比如 is being watched)。而完成结构后面要求过去分词,be 的过去分词是 been,所以必须是 have been。

I have being studying.
✗ have 后面必须是过去分词,being 是现在分词
I have been studying.
✓ have + been(过去分词)+ studying

为什么 doing 不能换成 do / did?

been 后面接的是进行结构,进行结构要求 -ing 形式,所以永远是 doing。这也是为什么"进行"那块的形式在整个时态里是固定的。

I have been working all morning.
我一上午都在工作。
She has been learning French.
她一直在学法语。 三单 → has been
小结:have → been → doing 是一条硬链,不能改成 being,也不能改成 do。最左边的 have/has 承担时态信息,后面两块形式固定。
4

时间线:完成时 vs 完成进行时,差在哪一段

怎么用 · 三种过程形态 + 时间状语
要解决:和现在完成时到底差在哪?三种"过程形态"怎么落进句子? 上一阶的局限:形式落地了,但"过程"这个概念本身还需要一个可视化的对比,才不容易和完成时混。

时间线对比

现在完成时 —— 看"累积到现在的成果" 过去 现在 ●─────────────────────────▶ ✓ └── 结果被压成一个点 ──┘ 现在完成进行时 —— 看"一路延伸过来的过程" 过去 现在 ●━━━━━━━━━━━━━━━━━━━━━━━━▶ └── 过程被展开成一条线 ──┘

同一根"过去↔现在"的线,完成时把它压成一点(看结果),完成进行时把它拉成一条线(看过程)。这是两者最根本的差别,其他用法都是从这个差别长出来的。

三种"过程形态"

形态一:还在继续

I have been studying for three hours.
我已经连续学习三个小时了。 现在还在学

形态二:刚停下,留下痕迹

You have been running.
你刚才一直在跑步吧。 现在停了,但满头大汗、还在喘
Have you been crying?
你刚才一直在哭吗? 现在停了,但眼睛红着

形态三:最近这段时间一直如此

I have been working hard lately.
我最近一直工作得很努力。
She has been feeling tired recently.
她最近一直觉得累。

时间状语:给"这段过程"量尺寸

for→量长度for 3 hours / for two weeks
since→找起点since 8am / since 2006
all day→标整段all day / all morning / all week
lately→标近段lately / recently
持续到现在
for · since
all day
刚停,留痕
动作动词
+ 完成进行时
近期持续
lately
recently
小结:同一根线,完成时压成一点(看结果),完成进行时拉成一条线(看过程)。三种过程形态:还在继续 / 刚停留痕 / 近期持续;时间状语负责给这段过程量尺寸。
5

大坑:没有"过程"的动词,不能用进行

特殊情况 · 最容易错的点
要解决:为什么 I have been knowing him 是错的?和完成时那阶的大坑怎么对应? 上一阶的局限:前面说"过程",但有一类动词根本没有过程——它们只能表状态或瞬间。这类词套进行结构就错。

先分清三种动词:

动作动词→有过程study / work / read / rain / run
状态动词→没过程know / believe / own / belong / love(表状态)
短暂动词→没过程die / leave / marry / buy / borrow

只有第一类能进 have been doing。后两类都没有可被打开的"过程",套进去就错。

为什么错?把中文直译出来

I have been knowing him for ten years.
字面:我"持续认识"他十年 —— "认识"是一种状态,不是一个过程
I have been owning this car for three years.
字面:我"持续拥有"这辆车三年 —— "拥有"是状态
He has been leaving school for 10 years.
字面:他"持续离开"学校十年 —— 离开是一瞬间的
My grandpa has been dying for 2 years.
字面:祖父"持续死亡"两年 —— 荒谬

解决法:状态动词 / 短暂动词表"持续",用完成时

它们没有过程,但留下的状态可以延续到现在,正好交给现在完成时。和完成时那阶的"改主系表"是同一个逻辑。

know→have known认识 → 一直认识
own→have owned拥有 → 一直拥有
be dead→have been dead死亡状态 → 一直处于这个状态
be away→have been away离开状态 → 一直处于这个状态
I have known him for ten years.
我认识他十年了。
My grandpa has been dead for 2 years.
我祖父去世 2 年了。

但是——动作动词就是动作动词

如果动词本身有过程(teach、live、work、learn、read、rain),直接 have been doing,不用改:

I have been teaching English for 11 years.
我教英语 11 年了(还在教)。
It has been raining since last night.
从昨晚起一直在下雨。
小结:三种动词只有动作动词能配 have been doing。状态动词 + 进行 = 错,短暂动词 + 进行 = 错;两类都改用现在完成时 + 状态表达。
6

实战:和完成时二选一,怎么快速定

高级技巧 · 收尾判断
要解决:考试里两个"完成"老搞混,怎么一秒钟决定? 上一阶的局限:前面拆清了三个模块和三种动词;最后的难点是"看到句子,该选哪个"。

核心对照:同一件事,两种镜头

比的是现在完成时完成进行时
看的是结果、完成、成果过程、持续、一路
做完了吗通常已完成未必,可能还在做
时间线压成一点拉成一条线
例句I have painted the wall.
墙刷好了		I have been painting the wall.
我一直在刷墙
典型信号词already / just / yet
ever / never		for / since / all day
lately / recently

歧义句:有没有"进行",意思不一样

I have lived in Beijing. 光这一句有歧义,换形式就分开:

I have lived in Beijing.
我(曾经)在北京住过 —— 现在多半不住。
完成时 — 整段经历压成一个事实
I have been living in Beijing.
我一直在北京住着 —— 强调过程。
完成进行时 — 整段经历展开成过程
I lived in Beijing for 10 years.
我(曾经)在北京住了十年 —— 十年整体封在过去,现在已不住。

两种"完成"之外:三层模块的替换游戏

最后一个练手的点:如果会拆,就知道替换哪一块会得到什么时态。

have done→去掉"进行"现在完成时(看结果)
am doing→去掉"完成"现在进行时(只看此刻)
had been doing→换掉"现在"过去完成进行时(锚点在过去)
will have been doing→换掉"现在"将来完成进行时(锚点在将来)
小结:二选一时问自己一句——我在说"做完了什么",还是"一直在做"? 前者用完成时,后者用完成进行时。把三块拆开看,还能顺手推导出过去/将来完成进行时。

总览表

阶关注点关键内容一句话记忆
① 地基它是什么现在 + 完成 + 进行,三层叠加不是新时态,是三块拼的
② 解剖每块给什么进行给过程 / 完成给连接 / 现在给锚点去掉哪块,就变成别的时态
③ 形式怎么搭have/has + been + doing硬链,不能改 been / doing
④ 时间线和完成时差在哪完成压成一点,完成进行拉成线看结果 vs 看过程
⑤ 大坑过程的限制状态动词 / 短暂动词不能用进行没过程,别打开
⑥ 实战怎么定二选一;三层模块替换游戏问:说"做完啥"还是"一直在做"
