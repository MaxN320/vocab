现在完成进行时 · 阶梯式笔记

它存在的唯一理由:补上现在完成时的一个盲区——"过程"。整份笔记就围着这个对比走。

1

地基:它专门强调"过程",不是"结果"

是什么 · 一个最本质的点
要解决:已经有现在完成时了,为什么还要这个时态? 为什么需要:现在完成时的落点在"结果"——事情做完了、留下了什么。可有时我们想说的恰恰相反:不管做完没,我这一路一直在做。完成时框不住这条"过程本身"。

核心一句话:现在完成进行时 = 一个动作从过去持续到现在,镜头对准"一直在进行"这个过程。可能还在继续,也可能刚停,但重点永远是"这段持续",而不是"做出了什么结果"。

I have read the book.
我把书读完了。
现在完成时 — 镜头对准结果:读完了
I have been reading the book.
我一直在读这本书(可能还没读完)。
完成进行时 — 镜头对准过程:一直在读

记住这组对照,它就是整份笔记的主线。后面每一阶都在回答:这个"强调过程"的意思,怎么落到形式和用法上。

小结:同样连接"过去↔现在",完成时看结果,完成进行时看过程。抓住"镜头对准哪儿"这一点,全篇打通。
2

形式:过程怎么搭成句子

怎么用 · 造句的骨架
要解决:知道它强调过程了,句子长什么样? 上一阶的局限:地基只说清"表达什么",没给"句子的形状"。

公式一条:have / has + been + doing。拆开看正好是两个老朋友的拼接——

have/has + been 来自现在完成时(管"连到现在"),been + doing 那个 -ing 来自进行时(管"过程")。两块一拼,既连着现在、又强调进行,正好对应第一阶的意思。

I have been working all morning.
我一上午都在工作。
She has been learning French.
她一直在学法语。 三单 → has been
小结:骨架 have/has + been + doing = 完成时的"连到现在" + 进行时的 "-ing 过程",拼起来的。
3

怎么用:配时间状语,把"这段持续"说出来

怎么用 · 核心搭配
要解决:"一直在做"这个过程,怎么在句子里标出跨度? 上一阶的局限:形式解决"怎么搭",但一个过程总得说清"持续了多久 / 从何时起"。

三类常用时间状语,负责标出这段过程的长度或起点:

for + 一段时间

I have been studying for 3 hours.
我已经学了3个小时了。

since + 过去时间点

She has been working since 8am.
她从早上8点起一直在工作。

all day / all morning(整段时间)

He has been sleeping all day.
他睡了一整天。

和完成时的 for/since 长得一样,但这里的重点不同:完成时用它们量"结果累积到现在有多久",完成进行时用它们量"过程持续了多久"——差别还在那个"镜头对准哪儿"。

小结:for 标时长、since 标起点、all day 标整段;它们都是给"这段过程"量尺寸的。
4

高级:一眼分清"它 vs 现在完成时"

高级技巧 · 实战抓手
要解决:实战里两个时态老搞混,怎么快速判断? 上一阶的局限:前面讲清了它自己;但真正的难点是它和现在完成时的边界。

它自己的信号词

除了 for/since/all day,还有两个偏它的词:

lately 最近 recently 近来
I have been feeling tired lately.
我最近一直觉得累。

核心对照:同一件事,两种镜头

比的是现在完成时完成进行时
镜头对准结果、完成过程、持续
做完了吗通常已完成未必,可能还在做
例句 I have painted the wall.
墙刷好了		 I have been painting the wall.
我一直在刷墙
言下之意看成果看这一路的付出/持续
小结:lately/recently 偏它;和完成时二选一时,问自己一句——我在说"做完了什么",还是"一直在做"? 前者用完成时,后者用完成进行时。
