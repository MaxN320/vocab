过去完成进行时 · 阶梯式笔记

一条主线:名字唬人,其实是两样你已会的东西叠一起——过去完成时(06)的"落脚点在过去" + 进行时(02/05)的"过程一直铺着"。

1

地基:过去落脚点之前,一直在进行

是什么 · 一个最本质的点
要解决:过去完成进行时到底在表达什么? 为什么先讲:名字长(过去+完成+进行)吓人,但拆开就是两件旧事:过去完成时(06)"站在过去某刻回看",再加进行时"过程一直铺着、持续"。

核心一句话:站在过去某一刻(Time 1),回看一个从更早(Time 0)一路持续、进行到那个落脚点的过程。had been doing = "在那个过去点之前,一直在做"。

把名字拆成三层:过去(落脚点在过去) + 完成(回看那个落脚点之前) + 进行(强调过程一直铺着、持续)。

Time 0 ●━━━━━━━━━━━━━● Time 1 ────── 现在
Time 0 过程开始(更早)　　Time 1 过去落脚点
中间整条 had been doing ← 一直在进行 / 持续(是一条线,不是一个点)
She had been cooking before I came in.
我进来之前,她一直在做饭。 做饭从更早一路持续到"我进来"这个点
小结:它就是"过去的过去"再加一条"一直在进行"——落脚点在过去(Time 1),过程从更早(Time 0)一路持续到那儿。
2

形式:had + been + doing

怎么用 · 造句的骨架
要解决:句子怎么搭? 上一阶的局限:地基说清"表达什么",没给"句子的形状"。

公式三段:had + been + 动词-ing。had(全人称通用) + been(be 的过去分词,永远不变) + doing(现在分词,表进行)。

had + been + doing　　←　把 06 的 had done 里的 done,换成 been doing
They had been waiting for a long time.
他们已经等了很久了。
I hadn't been sleeping well those days.
那些天我一直没睡好。
Had you been waiting long?
你等很久了吗?
小结:had + been + doing 三段固定:had 全人称、been 不变、doing 表进行。就是 06 的 had done 把 done 换成 been doing。
3

功能:从过去某时,持续到过去另一点

怎么用 · 用在哪些场景
要解决:什么时候用? 上一阶的局限:形式解决"怎么搭",没说"用在哪"。

① 过去某时开始,持续到过去另一个时间点

She had been cooking before I came in.
我进来之前,她一直在做饭。 从更早一路持续到"我进来"

② 强调"一直在进行"——持续了多久

He had been running for an hour when it started to rain.
开始下雨时,他已经跑了一个小时了。 for an hour = 强调持续时长

for + 时长 是它的常见搭配,专门强调"到那个过去落脚点为止,已经进行了多久"。

③ 用"一直在进行的动作",解释过去的结果 / 状态

这是它最出彩、最容易被漏掉的用法:过去某个状态 / 结果,是因为之前一直在进行某个动作。动作也许刚停,但它造成的结果在那个过去点上仍然重要——had been doing 就交代那个"前面一直在做的事"当原因。

Jason was tired because he had been jogging.
Jason 很累,因为他之前一直在跑步。 跑步→累(前因后果)
The ground was wet because it had been raining.
地是湿的,因为之前一直在下雨。 雨也许刚停,但"地湿"这个结果还在

注意:这一类常常没有 for + 时长,重点不在"多久",而在"这个一直在进行的动作,造成了后来的结果"。

小结:两大用法:一是从过去某时持续到过去另一点(常配 for + 时长,强调多久);二是用"之前一直在进行的动作"解释过去的结果 / 状态(常无时长)。
4

对比:had done vs had been doing

怎么用 · 结果 vs 过程
要解决:它跟过去完成时(06)差在哪? 上一阶的局限:它自己讲清了,但最容易和 06 混,这一阶专门切开。

一刀切开:一个看结果,一个看过程。

When you called, I had finished my work.
你打来时,我已经把活干完了。
had done → 看结果:完没完(工作做完了)
When you called, I had been working for hours.
你打来时,我已经连着工作好几小时了。
had been doing → 看过程:做了多久、一直在做

再体会一次"结果 vs 过程"的味道差别:

He had cleaned the car.
他把车洗好了。 看结果:车现在干净了
He had been cleaning the car.
他(之前)一直在洗车。 看过程:也许还没洗完、身上湿漉漉的

这跟"现在完成时 vs 现在完成进行时"(have done vs have been doing)是同一刀,只是落脚点从"现在"挪到了"过去"。

边界:状态动词不用 had been doing

和进行时家族一个规矩(02 讲过):状态动词(be / have / know / like / understand / belong…)没有"过程"可展开,不进进行形式。想表"到过去某点前一直……",改用过去完成时 had done。

The car had been belonging to him for years.
belong 是状态,不能用 been doing
The car had belonged to him for years.
状态动词 → 用 had done
We had known each other for years before we became friends.
know 同理,用 had known
小结:had done 看结果(完没完),had been doing 看过程(做了多久、一直在做);状态动词只能用 had done。同一刀,落脚点在过去。
5

常用搭配:before / when / by the time

怎么用 · 谁来标"过去落脚点"
要解决:哪些词是它的信号? 上一阶的局限:会区分了,给信号词抓手。

它离不开一个过去落脚点(Time 1)。before / when / by the time 就是负责领出那个点的连接词——从句里的动词用一般过去时(那个点),主句用 had been doing(持续到那个点)。

She had been cooking before I came in.
我进来前,她一直在做饭。 before → 落脚点 I came in
He had been running for an hour when it started to rain.
开始下雨时,他已跑了一小时。 when → 落脚点 it started to rain
By the time she arrived, I had been waiting for two hours.
她到的时候,我已经等了两个小时了。 by the time → 落脚点 she arrived

by the time 尤其爱配它——"到……的时候,已经(持续)……了"。时长除了 for + 时段,也能用 since + 起点:She had been working there since 2010.;问时长用 How long had you been waiting?

小结:before / when / by the time 领出过去落脚点(从句用一般过去时),主句 had been doing 表"持续到那个点";时长用 for + 时段 或 since + 起点。
6

判断:四种完成时,一起看

收口 · 把整族摆上桌
要解决:什么时候真的用它?它在整个"完成家族"里站哪? 上一阶的局限:它自己讲透了,最后把四种完成时摆一起,一眼看清坐标。

用它的两个条件,缺一不可:① 有过去落脚点(Time 1);② 强调"到那点之前一个过程一直在进行",而不是"完成了一件事"。只想说"完成了"→ 用 had done;没有过去落脚点 → 用过去进行时 / 一般过去时。

四宫格:横看落脚点,竖看结果/过程

看结果(完成)看过程(完成进行)
落脚点 = 现在 have done现在完成时(03) have been doing现在完成进行时
落脚点 = 过去 had done过去完成时(06) had been doing过去完成进行时(本篇)

横轴:落脚点在现在还是过去(have / had);纵轴:你要结果还是过程(done / been doing)。本篇 = 落脚点在过去 + 看过程那一格。

小结:它是四种完成里"落脚点在过去 + 看过程"的那一格。有过去落脚点、且强调持续过程,才用 had been doing。
