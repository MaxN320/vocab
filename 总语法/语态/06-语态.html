语态

整章只解决一个问题：主语和动词是什么关系。主语发出动作，是主动；主语承受动作，是被动。被动语态本身只有一个公式 be + done，难在它从不单独出现：一个动词要变成谓语，先定语态，再叠时态，最后叠情态。三层叠好，才是一个完整的谓语。

阶段一

语态：主语和动词的关系

动词要变成谓语，得过三关：语态、时态、情态。语态是第一关 —— 写句子先定主语，再定动词，两样一定下来，它们的关系就定了。

谓语动词的三态管什么例
语态主语和动词的关系：主动还是被动clean ／ be cleaned
时态动作的时间和状态：4 个时间 × 4 种状态 ＝ 16 种cleans ／ cleaned ／ has cleaned …
情态说话人的态度：必须、能、可以、应该，还有推测must clean ／ can clean ／ should clean …

发出者与承受者

I cleaned my room.

主动语态：主语 I 是 clean 的发出者。动词不用做任何变化，该用什么时态就用什么时态。

My room was cleaned.

被动语态：主语 my room 是 clean 的承受者。动词要变成 be + done。

📖 语态是第一个定下来的"态"

语态讨论的只是主语和动词这两样东西的关系。写句子时，主语和动词一选定，主动还是被动就已经定了；时态、情态都要等它定了再往上叠。

别看中文有没有"被"

My room has been cleaned.

我的房间打扫干净了。

中文一个"被"字都没有，英文却必须用被动：房间不会自己打扫自己。

Paper is made from wood.　English is spoken in many countries.

纸是用木头做的。／ 很多国家都说英语。

反过来，中文看着像主动的，也不一定。"老头晒太阳"：看着像老头在"晒"太阳，其实是太阳晒老头。英语不这么造句，而是换一个动词：

The old man is basking in the sun.

老头在晒太阳。（bask 是不及物动词，只能用主动）

📖 判断标准只有一个

在英语里选定的那个动词面前，主语是发出者，还是承受者？中文有没有"被"字不算数，中文句子的主语也不一定就是英语句子的主语。

看词性：及物动词才有被动

"门关了"，是门自己关，还是被关上？"喇叭响着"，是自己响，还是被按响？"人穿着西装"，是主动还是被动？这类问题常让人犯糊涂。答案是：不由感觉决定，由动词的词性决定。

I love you. → You are loved.

love 是及物动词，有承受者 you，承受者才能被提到前面当被动句的主语。

I swim. → … is swum

swim 是不及物动词，没有承受者，被动语态根本变不出来。

📖 及物才有被动

及物动词（词典标 VN 或 [T]）→ 有被动　｜　不及物动词（标 V 或 [I]）→ 没有被动

很多动词两种词性都有，就得看这一句用的是哪一种。比如查词典，shut 既标了 VN，也标了 V。

Someone shut the door. → The door was shut.

shut 作及物动词：门是被关上的。

The door won't shut.

shut 作不及物动词：门关不上。主动形式，不用被动。

He is wearing a suit.

wear sth：人穿衣服，人是发出者 → 主动。

He is dressed in a suit.

dress sb：给某人穿衣打扮，人是承受者 → 被动。

🧷 被问"主动还是被动"，先反问一句

"你用的是哪个词？"—— 同样是"穿"，wear 用主动，dress 用被动。确定了词，再查词典看它及物不及物。

最常用的两个答案：查词典；不知道（信息不够时，别硬猜）。

这些动词没有被动

类别常见词错例 → 正确
不及物动词happen、occur、take place、appear、disappear、arrive、die、rise、lastThe accident was happened. → The accident happened.
不及物短语belong to、consist of、break out、come true、run outThe book is belonged to me. → The book belongs to me.
系动词look、sound、smell、taste、feel、seem、becomeThe soup is tasted good. → The soup tastes good.
表关系的及物动词have（拥有）、fit、suit、lack、resemble、costA car is had by him. → He has a car.
📖 为什么它们变不了被动

不及物动词和短语：没有承受者。happen、take place 最容易误用 —— 中文"发生了"听着像被动，英语里它们只能主动。

系动词：连接主语和表语，描述状态，不是动作。

表关系的动词：虽然后面有宾语，但宾语没有"承受"任何动作。He has a car，车并没有被怎么样。

rise 和 raise 常一起考：rise 不及物（Prices rose），raise 及物（Prices were raised）。

小结：语态就是主语和动词的关系：主语是发出者用主动，是承受者用被动 be done。别看中文有没有"被"字，也别凭感觉，要看英语里选的那个动词及物不及物：及物才有被动。不及物动词、系动词、have 这类表关系的动词，都没有被动。

阶段二

被动怎么写：be done × 时态

第一关定下来是被动，就先写出 be + done。

但 be done 从来不单独用 —— 光写 It be called … 成不了句子。第二关要叠上时态，而时态全由那个 be 来承担。

先语态，再时态

We have an old piano at home. It is called "Old Lady". It was made in Vienna in 1890. At the moment it is being repaired.

我们家有一架老钢琴，名叫"老太太"，1890 年在维也纳制造。眼下它正在维修。

原文是一段讲古钢琴（clavichord）的短文，三句被动的写法和这里一模一样。

一

它 · 叫作 → be called → It is called …

语态：钢琴不会给自己起名 → be called。时态：名字是一直如此的客观事实 → 一般现在时。

二

它 · 制造 → be made → It was made in 1890.

语态：钢琴是被造的 → be made。时态：给了过去的具体时间 → 一般过去时。

三

它 · 修理 → be repaired → It is being repaired.

语态：被修 → be repaired。时态：此刻正在进行 → 现在进行时。

📖 被动不难，难的是叠加

单看被动，几乎没有难度：被叫作 be called，被制造 be made，被修理 be repaired，一律 be + done。

难在要一边想语态，一边想时态 —— 大脑从"单核"变成了"双核"。所以一定要分步：先写 be done，再给 be 加时态。

be 负责时态

把 be 当成一个普通动词，代进时态公式里，被动就出来了：

时态公式把 be 代进去被动
现在进行：am / is / are + doingbe 的 doing 形式 → beingam / is / are + being + done
现在完成：have / has + donebe 的 done 形式 → beenhave / has + been + done
一般将来：will + dobe 的原形 → bewill + be + done
🧷 最容易丢的是 being

It is being repaired.

现在进行时的被动：此刻正在被修。

It is repaired.

丢了 being，句子还像被动，时态却变成了一般现在时。

写得越快越容易丢。宁可慢一点，一步一步写。

十种时态有被动

时态主动被动例
一般现在do / doesam / is / are doneThe office is cleaned every evening.
一般过去didwas / were doneThe bridge was built in 1937.
一般将来will dowill be doneThe meeting will be held on Monday.
过去将来 would dowould be doneWe were told the results would be announced soon.
现在进行am / is / are doingam / is / are being doneMy car is being repaired.
过去进行was / were doingwas / were being doneThe road was being repaired.
现在完成have / has donehave / has been doneMy key has been stolen.
过去完成had donehad been doneAll the tickets had been sold.
将来完成will have donewill have been doneThe bridge will have been finished by May.
过去将来完成 would have donewould have been doneHe said the work would have been done by June.

常说的是八种，没有把"过去将来"这一组算进去。严格说，16 种时态里有被动的是十种。

没有被动的时态

将来进行：will be doing → will be being done

拼出来太绕，几乎没人用 → 改用一般将来 will be done。

完成进行：have been doing → have been being done

四种完成进行时全部没有被动 → 改用完成时 have been done。

🧷 用排除法记

将来进行、完成进行 —— 全军覆没；其余的都有被动。

📖 顺便复习：完成进行 ＝ 持续

完成进行时可以统一理解成"持续"，名字前面的字告诉你持续到什么时候：

现在完成进行：持续到现在，一般带时间段 —— I have been learning grammar for two weeks.

过去完成进行：持续到过去某一点，后面一定跟着那个点 —— by last week，或一个 did 的句子（when my friend arrived）。

将来完成进行：持续到将来某一点 —— by next week，或一个 do / does 的句子（when my friend arrives：时间状语从句用一般现在时表将来）。

后两种实际很少见：完成时加上时间段，本身就能表示持续。所以完成进行没有被动，并不可惜 —— 用完成时就够了。

🧷 不要自己发明形式

有个真实的糗事：有人中学时想给自己起个英文名叫"新房客"，查不到，就自己造：住 live，加 -er 变成"住的人"，前面加 new —— new liver。后来外教一愣，才知道 liver 是"肝"。

语法形式也一样：照着公式硬套出来的 will be been done、have been being done，英语里并没有。

疑问与否定：不借 do

How often are these windows cleaned?

✓ 被动句本身有 be，直接把 be 提前。

How often do these windows cleaned?

✗ 被动句用不着 do。

When was the light bulb invented?　We weren't invited to the party.

电灯泡是什么时候发明的？／ 我们没被邀请去参加聚会。

Has the parcel been delivered yet?　Will the results be announced today?

包裹送到了吗？／ 结果今天会公布吗？

📖 和主动句同一条规则

疑问和否定，都由谓语里的第一个助动词负责：它提前构成疑问，它后面加 not 构成否定。被动句的第一个助动词是 be、have 或 will，所以根本轮不到 do。

小结：先写 be done，再把 be 当普通动词代进时态公式：进行时加 being，完成时加 been，将来时加 will be。十种时态有被动，将来进行和完成进行没有，改用一般将来和完成时。被动句的疑问、否定靠第一个助动词，不借 do。别自己套公式造形式。

阶段三

难的不是被动，是时态

上一阶已经看到：被动本身几乎没有难度。

真正出错的地方在时态：句子里的关键词决定时态，时态决定 be 长什么样。这一阶专门练这一步。

按时态认被动

句子时态为什么
Paper is made from wood.一般现在客观事实
This house was built a hundred years ago.一般过去a hundred years ago
I think I'm being followed.现在进行此刻有人跟着我
We had to take another road — the main road was being repaired.过去进行had to 说的是过去；当时路正在修
My bike has been stolen.现在完成过去被偷，现在没车骑
When we arrived, all the tickets had been sold.过去完成先卖光，后才到：要有一个过去的动作作参照
The wedding will be held in a small church.一般将来还没举行

关键词决定形式

句子关键词答案
You can't use the meeting room right now. It ___ (clean).right now；现在用不了is being cleaned
She didn't come to the dinner. She ___ (not / invite).didn't come：过去wasn't invited ／ hadn't been invited
The heater was broken last week, but it works fine now. It ___ (fix).过去坏了，现在好了has been fixed
By next month, this bus ___ (drive) by Mr Li for ten years.by next month ＋ for ten yearswill have been driven
At this time yesterday, the trees ___ (plant) by the students.at this time yesterdaywere being planted
The results ___ (announce) next Friday.next Fridaywill be announced
📖 逐题看关键词

第一题：写成 is cleaned，就成了"平时被打扫"，和"现在用不了"对不上；正在打扫，才用不了。

第二题：只说当时没被邀请，用一般过去 wasn't invited；想强调"先没被邀请、所以后来没去"，用过去完成 hadn't been invited。两个都对。

第三题：过去坏、现在好，要用现在完成 has been fixed，突出过去的动作对现在的影响。写成过去完成 had been fixed，反而成了"先修好，后来又坏了"。

第四题："到将来某一点，已经持续了一段时间"，本该用将来完成进行 —— 可它没有被动，只能用将来完成 will have been driven。简单说成一般将来 will be driven 也行。注意 drive 的过去分词是 driven。

第五题："昨天此刻"是过去的一个时刻，没说持续 → 过去进行 were being planted，别想成过去完成进行。

🧷 时态关键词速记
关键词时态
always、every day、usually一般现在
yesterday、last week、in 1890、… ago一般过去
now、right now、at the moment现在进行
at this time yesterday、at 9 last night过去进行
already、just、yet；过去的事影响到现在现在完成
by / before + 过去某一点；过去某个动作之前过去完成
tomorrow、next week一般将来
by + 将来某一点（常带时间段）将来完成

at 还是 by：在那一刻，还是到那一刻

At this time yesterday, the trees were being planted.

at：就在那一刻 → 正在种 → 过去进行。

By this time yesterday, the trees had been planted.

by：到那一刻为止 → 已经种完 → 过去完成。

📖 介词一换，时态跟着换

有人会问：有没有可能昨天此刻之前，树就已经种完了？可能 —— 但那样的话，英语会换介词，说 by this time yesterday 或 before this time yesterday。

中文"在这一刻"和"到这一刻"听着差不多，英语分得很清：at 是"在那一刻"，by / before 是"在那一刻之前"。想说"做完了"，时间状语就得换成 by。

主从句时态一致

They were told that the results would be announced the following week.

他们被告知，结果将在下一周公布。

一

results · announce → be announced

语态：结果是被公布的。

二

下一周 → will be announced

时态：还没公布，是将来。

三

主句 were told 是过去 → would be announced

站在过去看将来，will 变 would：过去将来时的被动。

宾语从句的时态要和主句呼应，名词性从句篇讲过。叠上被动，道理不变：变的永远是那个助动词。

小结：被动写错，多半错在时态。先找关键词定时态，再把时态落到 be 上。right now 用进行，过去坏现在好用现在完成，by + 将来点用将来完成；at 是"在那一刻"，by 是"到那一刻"。主句是过去时，从句的将来要变成 would be done。

阶段四

看不出来的被动

前三阶的被动都有一个明显的标志：be done。

可有的被动句里根本没有 be done，有的 be done 又不是被动。下面是五种"伪装"。

need / want / be worth + doing

先补一个小知识：动词加 -ing 可以当名词用，叫动名词（非谓语动词篇细讲）。下面三个词后面接动名词时，形式是主动，意思却是被动：

The strap needs to be repaired. → The strap needs repairing.

need to be done→need doing：更常见，也更简洁

包带需要修一修。（包带不会自己修自己，意思是被动的）

This shirt needs ironing.

这件衬衫得熨一下。

《摩登家庭》里就有一句 This needs ironing，没说 needs to be ironed。

This book is worth reading. ／ This book is worth being read.

这本书值得一读。（be worth 后面只用主动的 doing）

🧷 只限这三个

need doing ／ want doing ／ be worth doing

want doing 当"需要"讲，多见于英式英语：The grass wants cutting.（草该剪了）。别的动词后面的 doing 没有这种被动意思。

have sth done：人的遭遇

My wallet was stolen. → I had my wallet stolen.

以物作主语→以人作主语：讲这个人碰上了什么事

我的钱包被偷了。

I had my request turned down.　He had his car broken into last night.

我的请求被拒了。／ 他的车昨晚被人撬了。

I had my heart broken once.

我也曾心碎过。（讲自己被伤过心的经历）

📖 语序：have + 宾语 + 过去分词

宾语承受动作，所以用过去分词 —— 和非谓语动词篇"宾补位上的 done"是同一个道理。语序一乱，意思全变：

I had my wallet stolen.

have + 宾语 + done：我的钱包被偷了。

I had stolen my wallet.

had + done 连在一起就成了过去完成时："我偷了我自己的钱包"。

🧷 have sth done 还有一个意思：请人做

I had my hair cut yesterday.　We're having the kitchen painted.

我昨天理了发（理发师剪的）。／ 我们正请人粉刷厨房。

同一个结构，靠语境区分：主语想要的事（理发、刷墙、修车）是"请人做"；不想要的事（被偷、被撬、被拒）是"遭遇"。口语里也常用 get sth done：I need to get my phone repaired.

get done：口语里的被动

表示被动，九成用 be done，还有一成用 get done。

They got married last year.　He got hurt playing football.　She got caught cheating.

他们去年结了婚。／ 他踢球时受了伤。／ 她作弊被抓了。

📖 get 强调"变了"

get 本义是"变得、成为"。get done 多用于口语，强调状态的变化（没结婚 → 结婚）或意外（没事 → 受伤、被抓）；be done 更中性，书面语多用它。

注意 get 是实义动词，疑问、否定要借 do：Did he get hurt? —— 这一点和 be done 正好相反。

主动形式表被动的另外两类

This book sells well.
The pen writes smoothly.
The door won't open.

及物动词当不及物用，描述东西本身的性质：这书好卖，这笔好写，门打不开。主语是承受者，却只能用主动。

The question is easy to answer.
The river is dangerous to swim in.

形容词 + to do：主语是 to do 的承受者，不定式却用主动。easy to be answered 是错的。

📖 easy to do 为什么用主动

It is easy to answer the question. → The question is easy to answer.

原句里 to answer 本来就是主动的，只是把它的宾语 the question 提到前面当了主语，不定式照旧。所以介词也不能丢：dangerous to swim in（swim in the river）。

be + 过去分词，不一定是被动

The shop is closed.
The window was broken when I got there.

系表结构：closed、broken 是形容词，描述状态 —— 商店关着门；我到时窗户是破的。

The shop is closed at six every day.
The window was broken by a stone.

被动语态：描述动作 —— 商店每天六点关门；窗户被石头打破。

📖 看它描述的是动作还是状态

带 by + 执行者、时间、频率的，多半是被动（动作）；能在前面加 very、能换成普通形容词的，多半是系表（状态）。

be interested in ／ be tired of ／ be married ／ be dressed in ／ be lost ／ be finished

这些大多已经形容词化，当系表理解就行。非谓语动词篇的 -ing / -ed 形容词（boring / bored），就是这个道理。

小结：没有 be done 的被动有五种：need / want / be worth doing；have sth done（遭遇，也可以是请人做）；get done（口语，强调变化）；sell well 这类性质描述；easy to do。反过来，be + 过去分词描述状态时是系表，不是被动。

阶段五

什么时候用被动、怎么变

前四阶讲的是被动"怎么写"。

还有两个问题：什么时候该用被动？一个主动句又怎么变成被动句？这一阶来讲。

为什么要用被动

例为什么用被动
My bike has been stolen.不知道是谁偷的
English is spoken in many countries.说英语的人太多，没必要说
The results will be announced on Friday.谁来公布不重要，重要的是结果
The Great Wall was built over many centuries.要谈的话题是长城，让它当主语
Three people were injured in the accident.新闻、科技、公文追求客观
Mistakes were made.不想说是谁犯的错（常被批评为推卸责任）
📖 被动的本质是"换主语"

谁当主语，谁就是这句话的话题。执行者不知道、不重要、不想说的时候，就把承受者推上主语的位置 —— 这就是被动。所以被动不是"主动的另一种说法"，而是换了一个说话的角度。

by 短语：大多数时候不用

The Mona Lisa was painted by Leonardo da Vinci.

执行者是重要的新信息，才用 by 引出，放在句末 —— 信息重心在后。

The window was broken by someone.

by someone、by people 等于没说，直接删掉。

by 后面用宾格：written by her，不是 by she。

主动变被动：三步

一

They built this bridge in 1937.

找到宾语 this bridge：只有带宾语的句子才能变被动。

二

This bridge …

宾语提到前面作主语。

三

built → was built

谓语变 be + done，时态不变：主动是一般过去，被动的 be 也用一般过去。

四

This bridge was built in 1937 (by them).

原主语变成 by + 宾格；泛指的 they、people 直接省掉。

🧷 最容易忘的是"时态不变"

They are building a new school. → A new school is being built.
Someone has taken my pen. → My pen has been taken.

双宾语与宾补的被动

主动被动要点
They gave him a prize.He was given a prize. ／ A prize was given to him.两个宾语都能作主语；物作主语时，人前面加 to（buy、make 加 for）
They elected her captain.She was elected captain.名词宾补原样留在后面
They made him wait.He was made to wait.主动省掉的 to，被动要还原
We saw him enter the building.He was seen to enter the building.同上
They kept us waiting.We were kept waiting.doing 宾补原样保留

短语动词：介词、副词一个不能丢

Her grandmother looks after the baby. → The baby is looked after by her grandmother.

孩子由外婆照看。

Nobody likes being laughed at.　The meeting has been put off until next week.

谁都不喜欢被人嘲笑。／ 会议推迟到下周了。

📖 短语动词是一个整体

look after、laugh at、put off 合起来才相当于一个及物动词，变被动时整块跟着走。The baby is looked by her grandmother，意思就全变了。take care of → be taken care of 也一样。

It is said that … ／ He is said to …

一

People say that he is rich.

主动：人们说他很有钱。

二

It is said that he is rich.

it 作形式主语，that 从句是真正的主语。

三

He is said to be rich.

把从句的主语提出来当主语，从句的谓语变成不定式。

The painting is believed to be worth millions.　Three people are reported to have been injured.

人们认为这幅画价值数百万。／ 据报道，有三人受伤。

说的是之前的事，不定式用完成式 to have done / to have been done（非谓语动词篇阶段八）。

🧷 新闻、学术写作的高频句型

It is said / believed / thought / reported / known / expected that …

读的时候统一理解成"据说、人们认为、据报道、众所周知"。不说是谁说的，只摆出说法 —— 这正是被动的客观性。

小结：执行者不知道、不重要、不想说，或者想让承受者当话题时，用被动；by 短语只在执行者是重要新信息时才用。主动变被动：宾语作主语，谓语变 be done 且时态不变，原主语变 by + 宾格或省略。双宾语两个都能当主语；省掉的 to 要还原；短语动词整块变被动。It is said that … 和 sb is said to do 是"据说"的两种写法。

阶段六

第三层：情态

语态、时态两层叠好，谓语还差最后一层。

情态表达说话人的态度：必须、能、可以、应该，还有"我猜"。情态动词一加进来，时态就要从 be 身上搬走。

情态动词的两个功能

情态动词后面只能接动词原形：must do、can do、may do、should do。常见的有 must、can、could、may、might、should、will、would。每个情态动词都有两个功能：

The best and most beautiful things in the world cannot be seen or even touched — they must be felt with the heart.

基本义：表达态度。cannot 是"不能"（没有这个能力），must 是"必须"。

It can't be true!

推测义：《乱世佳人》里，女主角听说北方军队要打过来，连说这一句。can't 不是"没能力"，而是"不可能是真的"。

🧷 这句名言的出处

它常被认为出自海伦·凯勒。她 1891 年写给菲利普斯·布鲁克斯牧师的信里，原话是 … cannot be seen nor even touched, but just felt in the heart，而且她说这是老师安妮·莎莉文教给她的。流传开的版本改成了 must be felt with the heart —— 恰好多出一个情态动词，语气从"描述"变成了"要求"。

📖 同一个情态动词，两种用法分开看

基本义表达说话人的态度：必须、能、可以、应该（本阶段和阶段七）。推测义表达说话人有几成把握（阶段八）。

记住：每一个情态动词都有这两个功能。读到情态动词，先判断它在表态度，还是在推测。

四个核心词的基本义

情态动词基本义例
must必须：责任、义务、强烈建议All passengers must wear seat belts.
can能力This stadium can be emptied in ten minutes.
can ／ may许可、请求You may sit or stand, as you wish.
should应该：温和的建议You shouldn't drink and drive.
📖 两两一对

must 和 should：都是建议，must 语气强（不能不做），should 语气弱（可以不做）。前几年公共场合"必须"戴口罩，用 must；现在流感季"应该"戴，用 should。

can 和 may：都能表示许可和请求，may 更委婉（阶段七）。

情态 ＋ 被动：时态转到情态上

情态动词 + be + done　（被动的 be 只能用原形）

例子："来来往往的飞机，日夜不绝于耳" —— 飞机能被听见：

一

planes · hear → be heard

语态：飞机是被听见的。

二

→ Planes are heard day and night.

时态：天天如此，一般现在时，时态落在 be 上。

三

→ Planes can be heard day and night.

情态："能"被听见。情态动词后面只能接原形，are 退回 be —— 时态改由 can 来体现（can 是现在时）。

再看一个过去的："（机场）当时没能被使用"：

一

it · use → be used → was used

语态：被使用；时态：then，过去。

二

It can was used.　It cannot be used then.

情态动词后面不能跟 was；可 can be used 又把"过去"丢了。

三

It could not be used then.

时态转移到情态动词上：can 变成过去式 could。

📖 时态住在谁身上

只有语态和时态：时态体现在 be 上 —— are heard、was used。

加上情态动词：be 被卡死成原形，时态只能搬到情态动词身上 —— can be heard、could be used。

写的时候按三步走，最保险：① 写 be done；② 加时态；③ 有情态，就把时态交给情态动词。一口气写，最容易丢词。

🧷 有的情态动词没有过去式

can → could、may → might、will → would 都有过去式；must、should、ought to 却没有。没有过去式时有两条路：换替身（must → had to，下一节），或者用"情态动词 + have done"（should have done 本应该，must have done 推测过去 —— 阶段七、八）。

比如："钱包昨天肯定是被人捡到了" —— must 没有过去式，写成 The wallet must have been found。

情态动词的替身

情态动词替身短语替身多出来的本事
musthave to能变时态：has to、had to、will have to
canbe able to能变时态，还能跟在别的情态动词后面：might be able to
shouldought to意思、用法完全一样
maybe allowed to表许可：Are we allowed to take photos here?
📖 替身存在的理由：时态

情态动词只有原形，顶多一个过去式，后面也只能接原形 —— 时态处处受限。替身短语里有 have、be 这样的普通动词，想变什么时态都行。所以情态动词和它的替身，最主要的区别在时态。

语法里凡是活下来的东西都有用处：没用的会被淘汰，比如 whom 越来越少见。have to 一直在，就是因为 must 办不到的时态，它能办到。

小结：情态动词 + 动词原形，有两个功能：基本义（必须、能、可以、应该）和推测义。四个核心词：must 必须，can 能力，can / may 许可，should 应该。情态 + 被动是"情态动词 + be done"；加了情态动词，时态就从 be 转移到情态动词上。情态动词时态受限，于是有了替身：have to、be able to、ought to、be allowed to。

阶段七

四组情态动词

上一阶说：情态动词和替身，最主要的区别在时态。

这一阶逐组看：must 与 have to、can 与 be able to 是重点，may 和 should 各有一个要记的点。

must 的两种否定

You mustn't say things like that.

形式否定 mustn't ＝ 禁止：你不准那样说话。

You needn't leave. ＝ You don't need to leave. ＝ You don't have to leave.

意义否定 ＝ 不必：你没必要走。

If you tell the truth, you don't have to remember anything.

说真话的人，什么都不必记。（马克·吐温，1894 年笔记）

反过来说：撒谎的人得记住每一个编出来的细节，不然就会被拆穿。

📖 "必须"的反面是"不必"，不是"禁止"

must 加上 not，意思是"必须不做" ＝ 禁止。想说"不必做"，得借 needn't、don't need to、don't have to。can 只有一种否定 can't，must 却有两种，这是它的第一个难点。

need 是半情态动词：needn't 是把它当情态动词用，自己就能否定；don't need to 是把它当实义动词用，要借 don't。两种意思一样。

must 与 have to

📖 区别一：时态（最主要）

must：只能表示现在和将来 —— I must finish my homework now. ／ We must study hard.（现在、将来都要）

have to：什么时态都行 —— has / have to（现在）、had to（过去）、will have to（将来）。

"昨晚我必须做作业"，must 表达不了（没有 musted，must 后面也不能接 did），只能用 had to。

📖 区别二：主观还是客观

must 偏主观：说话人自己认为必须。have to 主观、客观都能用：外部条件逼着你必须做的，用 have to。

My eyes aren't very good, so I have to wear glasses.

我视力不好，必须戴眼镜。（视力差 → 客观决定）

The doctor says I have to take this medicine three times a day.　In South Korea, men have to do military service.

医生说这药我一天得吃三次。／ 在韩国，男性必须服兵役。（医嘱、法律 → 客观）

🧷 have to 不等于"不得不"

初高中常见的说法是"must 必须，have to 不得不"。不准确：放进过去、将来里，had to、will have to 就是普通的"必须"。很多时候两个词可以互换；只有客观条件决定的事，才一定用 have to。

填 must 还是 have to答案为什么
I ___ take a taxi yesterday because the buses were on strike.had to过去的"必须"，只有 had to 能表达
We ___ get up early tomorrow — the train leaves at six.must ／ will have to有 tomorrow，两个都行；没有将来时间，只能用 will have to
My eyes aren't very good. I ___ wear glasses.have to前一句交代了客观原因

can 与 be able to

时态canbe able to
将来can（要带将来时间：one day）will be able to（不带时间也行）
现在can（口语里更常用）am / is / are able to（写作时换着用）
过去couldwas / were able to（有区别，见下一节）
完成时——have / has been able to
跟在情态动词后——（没有 might can）might / may / will be able to
练习答案
Lily ___ drive, but she doesn't have a car.can ／ is able to
I ___ (not) sleep well recently.haven't been able to（有 recently，用现在完成时，can 办不到）
Tom might ___ help us tomorrow.be able to（前面已经有情态动词 might）
🧷 《摩登家庭》：将来的"能"

Gloria 死活不承认自己老花眼，Jay 逼了她很久，她终于松口：I'll wear them（will 在这里表意愿：我愿意戴）。Jay 心里想的却是：以后我耳朵越来越背，她眼睛越来越花 —— I won't be able to hear her, she won't be able to see me，我们就能一直过下去了。

"将来会听不见"只能用 won't be able to。要是说 can't hear her，就成了"现在已经听不见了"。

could 与 was able to：成功做到

She could / was able to play the violin at five.

过去的能力（五岁就会拉），两个都行。

She was able to give a concert in London at eleven.

具体的某一次成功（十一岁真的开了音乐会），只能用 was able to。

这是一位小提琴神童的故事。要是写成 could give a concert，读起来就像"那时有能力开，但开没开成不知道"。

At first they didn't want to come, but we were able to persuade them.

一开始他们不想来，但我们成功说服了他们。（用 could，就成了"我们本有能力说服"，没说服成）

句子填为什么
Despite the heavy snow, we ___ get home in less than an hour yesterday.were able to昨天那一次，具体事件
I lived near the office, so I ___ get there in ten minutes.could ／ was able to没说哪一次，是过去的一般能力
When she was the manager, she ___ take a holiday whenever she wanted.could ／ was able to同上
I was very busy, but I ___ take a short holiday at Christmas.was able to圣诞节那一次，具体事件
📖 问一句：是不是具体的某一次？

是具体某一次做成了，只能用 was able to；只是说过去有这个能力，两个都行。否定时没有这个区别：couldn't 和 wasn't able to 都是"没能做到"。

📖 was able to 还在强调"不容易"

I took a photo 已经表示"拍了照"，为什么还要说 I was able to take a photo？因为后者强调困难：终于抓拍到了、爬到山顶才拍到了。

一条新闻：2012 年澳网男单决赛，德约科维奇和纳达尔打了近六个小时，报道写的是 Djokovic was able to beat Nadal —— 两人实力相当，赢得不容易。写成 Djokovic beat Nadal 也对，只是没了这层意思。

"难"是你自己觉得难就行，不用非得是买私人飞机、登珠峰：春运抢到一张火车票，也可以说 I was able to buy a ticket。

may 与 can：委婉程度

直白 → 委婉：can ＜ could ≈ may ＜ might

Can I have the phone now? → May I have the phone now?

我现在能用电话了吗？→ 请问我现在可以用电话吗？

有个片段：女儿对妈妈说 Can I…，妈妈马上纠正成 May I…。中文靠"请问"这类敬语表示客气，英语靠换一个情态动词。

Might I play your pianoforte?

我可以弹一下您家的钢琴吗？

电影《理智与情感》里，Marianne 到别人家做客时这样问。might 最客气，今天已经很少这么说了，但确实有这种用法。

should ＝ ought to；should have done

It's late and you're tired. You should go to bed.

很晚了，你也累了，该睡了。（现在应该做 → should do）

📖 过去的"应该"怎么说

should 和 ought to 意思、用法完全一样，也一样没有过去式，后面还只能接原形 —— 没法写 should went。

办法是借用完成式：should / ought to + have done 表示"过去应该做"。而过去"应该做"，本身就意味着当时没做。

She should have come to see me yesterday, but she forgot.

她昨天本该来看我的，却忘了。

You should have asked for permission before you left the table.

你离席之前，本该先问一声的。

决定答案的是 left：说的是过去的事。

You shouldn't have told him.

你本不该告诉他的。（shouldn't have done：本不该做，却做了）

🧷 别靠中文"本应该"来判断

中文说"他昨天应该来看我"，不一定会说出"本应该"三个字。判断靠时态线索：yesterday、forgot、left —— 说的是过去，就只能用 should have done。

小结：must 的否定有两种：mustn't 禁止，needn't / don't have to 不必。must 与 have to 主要区别在时态，其次 have to 能表客观；can 与 be able to 也是时态，be able to 还能跟在别的情态动词后面。过去具体某一次成功做到，只能用 was able to，它还带着"不容易"。may 比 can 委婉，might 最客气。should ＝ ought to，过去本该做却没做，用 should have done。

阶段八

情态的第二个功能：推测

前两阶讲的都是情态动词的基本义：必须、能、可以、应该。

每个情态动词还有第二个功能：推测 —— 说话人对一件事有几成把握。

可能性阶梯

例子：Tom 今天没来上课，Why is Tom absent?

说法把握谁会这么说
He is sick.100%：事实刚和他通过电话的好朋友
He must be sick.很有把握：有依据的推测早上看到他脸色发白的同桌
He may be sick.一半一半为了接老师的话，随口一说的同学
He could / might be sick.把握更小同上

He must be in pain.

他一定很疼。

一张新闻照片：一次握手之后，对方手上留下了一道道白印子。媒体写的是 must be，不是 is —— 那是从照片推出来的，不是本人说的。

📖 最有把握的，恰恰没有情态动词

陈述事实，直接用时态（He is sick）。一加情态动词，就说明这是推测：must 有依据、有条件，很有把握；may 一半一半；could、might 更没把握。

大致比例：must 约九成，may 约五成，could / might 更低。后两者实际差不多，不必抠数字。

推测里的 could 不表示过去

When I was young, I could swim for hours.

基本义：can 的过去式，过去的能力。

He could be at home now.

推测义：他现在可能在家 —— 说的是现在，could 只表示把握小。

这就是阶段六说的"两个功能要分开看"：同一个 could，在两套用法里意思完全不同。

否定的推测

It can't be true.

✓ 不可能是真的：很有把握的否定推测（《乱世佳人》那句）。

It mustn't be true.

✗ mustn't 只表示"禁止"，不能表推测。

🧷 肯定用 must，否定用 can't

He must be at home.（他一定在家）／ He can't be at home.（他不可能在家）／ He may not be at home.（他可能不在家）

推测过去：情态动词 + have done

例意思
He must have missed the train.他一定是没赶上火车。
She may / might have forgotten.她可能忘了。
He can't have said that.他不可能说过那种话。
The wallet must have been found by someone.钱包一定是被人捡到了。（被动）
📖 为什么都是 have done

情态动词后面只能接原形，没法接过去式。要把时间推到过去，就借完成式 have done —— 和 should have done、非谓语里的 to have done 是同一个办法。

You should have called me.

基本义：你本该给我打电话的（但没打）。

He must have called while I was out.

推测义：我出去的时候，他一定打过电话。

同样是"情态动词 + have done"，一个是遗憾，一个是推测。这部分在下一次"三态综合"课里细讲。

小结：推测的把握从高到低：直接用时态（is）＞ must ＞ may ＞ could / might。推测里的 could 不表示过去。否定推测用 can't，不用 mustn't。推测过去用"情态动词 + have done"，被动是 must have been done；它和 should have done 形式一样，一个推测，一个遗憾。

阶段九

边界：改错清单

前八阶把三层讲完了。

把最常见的错误集中放在一起：每一条都能在前面找到原因，改错时照着三层倒着查。

错例错在哪改正
The accident was happened last night.happen 不及物，没有被动（语态层）The accident happened last night.
The cake is tasted delicious.系动词没有被动（语态层）The cake tastes delicious.
The baby is looked by her grandma.短语动词丢了 after（语态层）The baby is looked after by her grandma.
I had stolen my wallet.（想说钱包被偷）语序错了，成了过去完成时（语态层）I had my wallet stolen.
I can't use my office. It is painted at the moment.丢了 being（时态层）It is being painted.
This bus will be drove by Mr Li.过去分词写错（时态层）will be driven
How often do these rooms cleaned?被动句不借 do（时态层）How often are these rooms cleaned?
The road has been being repaired for weeks.完成进行没有被动，是自造形式（时态层）The road has been under repair for weeks.
It can was used.　The wallet must had been found.情态动词后面只能接原形（情态层）It could be used. ／ The wallet must have been found.
You mustn't come tomorrow.（想说"不必来"）mustn't 是禁止（情态层）You don't have to / needn't come tomorrow.
Despite the snow, we could get home in an hour.具体某一次成功，不能用 could（情态层）we were able to get home in an hour
She should come to see me yesterday.过去的"应该"要用 should have done（情态层）She should have come to see me yesterday.
🧷 常写错的过去分词

drive – drove – driven ／ steal – stole – stolen ／ write – wrote – written ／ break – broke – broken ／ hide – hid – hidden ／ choose – chose – chosen

被动语态靠过去分词撑着，分词一写错，整个被动就塌了。做练习时，最常见的失分就在这里。

📖 改错时，三层倒着查

① 语态层：主语和这个动词是什么关系？这个词能不能有被动？短语动词、have sth done 的零件齐不齐？

② 时态层：关键词要求什么时态？be 的形式对不对？being、been 丢没丢？过去分词拼对没有？

③ 情态层：情态动词后面是不是原形？它需要的时态，这个情态动词给得了吗？给不了就换替身或用 + have done。

"under repair"（在修理中）、"under construction"（在建中）这类"under + 名词"，能代替没有的"完成进行被动"。

小结：错误分三层：语态层（不及物、系动词误用被动，短语动词丢零件，have sth done 语序），时态层（丢 being、分词拼错、借 do、自造形式），情态层（情态后变形，mustn't 当"不必"，could 当"成功做到"，过去的"应该"没用 should have done）。

阶段十

本质：换一个主角

到这里，可以把"主动""被动""情态动词"这些名字暂时放下了。

同一件事主角
Someone stole my wallet.小偷（可他是谁并不重要）
My wallet was stolen.钱包
I had my wallet stolen.我：讲我的遭遇
📖 语态是"换主角"的开关

主动和被动说的是同一件事，差别只在让谁当主语、让谁当话题。执行者重要，用主动；承受者重要，或者执行者说不出、不必说，用被动；想讲一个人的遭遇，用 have sth done。

一个谓语，是从里到外一层层叠出来的：

一

find

一个动作。

二

be found

语态：钱包是被找到的。

三

was found

时态：昨天的事，时态落在 be 上。

四

must have been found

情态：说话人推测"一定是"。must 后面只能接原形，时间改由 have been 来表示。

📖 英语把三件事都压在谓语上

英语的谓语要同时回答三个问题：谁对谁做（语态）、什么时候、做到什么程度（时态）、说话人怎么看（情态）。中文的动词几乎不变形，这些信息靠"被""了""着""必须""可能"这些词分头来带；英语全压在谓语动词这一小段上。

所以学英语的谓语，就是学这三层怎么叠：先语态，再时态，后情态。

语态也不只属于谓语。非谓语动词同样分主动、被动：being done、having been done、to be done、done —— 非谓语动词篇里的"主动用 doing，被动用 done"，就是语态在非谓语上的样子。

小结：语态决定谁当主角，时态决定什么时候、什么状态，情态决定说话人的态度和把握。三层从里到外叠：done → be done → 给 be 加时态 → 加情态动词，时态交给情态。

总览

使用总览与自检

速查一：十种时态的被动

状态有被动的时态
一般am / is / are done ／ was / were done ／ will be done ／ would be done
进行am / is / are being done ／ was / were being done（将来进行没有）
完成have / has been done ／ had been done ／ will have been done ／ would have been done
完成进行全部没有 → 改用完成时
加情态情态动词 + be done（现在）／ 情态动词 + have been done（过去）

速查二：长得不像被动的被动，和长得像被动的系表

结构例要点
need / want / be worth doingThe strap needs repairing.只限这三个
have sth doneI had my wallet stolen. ／ I had my hair cut.遭遇，或请人做
get doneHe got hurt.口语，强调变化；疑问借 do
sell / read / write … + 副词This book sells well.描述东西本身的性质
形容词 + to doThe question is easy to answer.不定式用主动
be + 过去分词（系表）The shop is closed.描述状态，不是被动

速查三：四个核心情态动词

情态动词基本义 · 替身 · 否定推测
must必须；替身 have to（过去用 had to）；mustn't 禁止，needn't / don't have to 不必must be 一定是；must have done 一定做过
can能力、许可；替身 be able to（过去成功做到用 was able to）；否定 can'tcan't be 不可能是；can't have done 不可能做过；could be 可能是（把握小）
may许可、请求（比 can 委婉）；替身 be allowed to；否定 may notmay be 可能是；may have done 可能做过
should应该；替身 ought to；过去的"应该"用 should have done（本该做，没做）should be 按理应该是

使用流程：写一个谓语的五步

  1. 定主语和动词。

    主语是这个动作的发出者，还是承受者？别看中文有没有"被"字。

  2. 查词性。

    这个动词在这里及物还是不及物？不及物动词、系动词、have 这类表关系的动词，直接用主动。拿不准就查词典。

  3. 写 be done。

    是被动，先写出 be + 过去分词，把过去分词拼对。短语动词整块带上。

  4. 叠时态。

    找关键词定时态，把时态加在 be 上：进行加 being，完成加 been，将来加 will be。没有被动的时态，换成最接近的一般将来或完成时。

  5. 叠情态。

    有情态动词，be 退回原形，时态交给情态动词（can → could）。情态动词给不了需要的时态，就换替身（had to、was able to），或者用"情态动词 + have done"。
