时态语态句库 · 03 / 16

现在完成时

过去的动作，现在的结果——讲的是过去在现在留下的影响。

看讲解：时态篇 03 →语态篇 →
信号词already · just · yet · ever · never · for · since · so far · recently
橙 谓语第一个词：扛时间，否定加 not、疑问提前都靠它蓝 时态的其余部分紫 被动：be + done绿 疑问词
公式要点A 主动↔被动B 只有主动

公式

主动
陈述主语 + have / has + done
否定主语 + haven't / hasn't + done
一般疑问Have / Has + 主语 + done？
特殊疑问疑问词 + have / has + 主语 + done？
被动
陈述主语 + have / has + been done
否定主语 + haven't / hasn't + been done
一般疑问Have / Has + 主语 + been done？
特殊疑问疑问词 + have / has + 主语 + been done？

do＝动词原形　doing＝现在分词　done＝过去分词　疑问词＝when / where / why / how / what …

要点

  • 现在完成时不跟 yesterday、ago、when 连用。问「什么时候」要换成一般过去时：When did they deliver it?（✗ When have they delivered it?）
  • already 用在肯定句；否定句、疑问句换成 yet，放在句尾：Has it been delivered yet?
  • have been to 去过（已经回来了）；have gone to 去了（还没回来）。

A · 主动 ↔ 被动12 组

同一件事说两遍：先让做事的人当主语（主动），再让被做的东西当主语（被动）。每边四句：陈述 → 否定 → 一般疑问 → 特殊疑问。

A01cancelcancelled · cancelled取消
主动
陈述
They have cancelled the meeting.
他们取消了会议。
否定
They haven't cancelled the meeting.
一般疑问
Have they cancelled the meeting?
Yes, they have. / No, they haven't.
特殊疑问
Why have they cancelled the meeting?
他们为什么取消会议？
被动
陈述
The meeting has been cancelled.
会议取消了。
否定
The meeting hasn't been cancelled.
一般疑问
Has the meeting been cancelled?
Yes, it has. / No, it hasn't.
特殊疑问
Why has the meeting been cancelled?
会议为什么取消了？
