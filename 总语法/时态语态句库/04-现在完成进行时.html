现在完成进行时

从过去一直做到现在（可能还在做），镜头对准「一直在做」这个过程。

看讲解：时态篇 04 →语态篇 →
信号词for · since · all day · all morning · how long · lately
橙 谓语第一个词：扛时间，否定加 not、疑问提前都靠它蓝 时态的其余部分紫 被动：be + done绿 疑问词
公式要点被动怎么办句库

公式

主动
陈述主语 + have / has + been doing
否定主语 + haven't / hasn't + been doing
一般疑问Have / Has + 主语 + been doing？
特殊疑问疑问词 + have / has + 主语 + been doing？
被动
没有被动（见下面「被动怎么办」）

do＝动词原形　doing＝现在分词　done＝过去分词　疑问词＝when / where / why / how / what …

要点

  • 完成进行时没有被动。想说被动，就只说结果（has been repaired），或者只说正在做（is being repaired）。
  • 常和 for、since、all day、how long 连用，强调「一直在做」。

被动怎么办

这个时态没有被动——照公式硬拼出来的形式，英语里不用。

✗ The road has been being repaired since last week.
✓ They have been repairing the road since last week.（改用主动）
✓ The road has been repaired.（只说「修好了」）
✓ The road is being repaired.（只说「正在修」）

句库10 组

这个时态没有被动，只练主动四句：陈述 → 否定 → 一般疑问 → 特殊疑问。

01waitwaited · waited等
主动
陈述
I have been waiting for you for an hour.
我等你等了一个小时了。
否定
I haven't been waiting long.
一般疑问
Have you been waiting long?
Yes, I have. / No, I haven't.
特殊疑问
How long have you been waiting for me?
你等我多久了？
