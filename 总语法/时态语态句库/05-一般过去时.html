时态语态句库 · 05 / 16

一般过去时

动作封在过去，和现在切断——只说「那时发生了」。

看讲解：时态篇 05 →语态篇 →
信号词yesterday · last week · … ago · in 2020 · just now · when I was young
橙 谓语第一个词：扛时间，否定加 not、疑问提前都靠它蓝 时态的其余部分紫 被动：be + done绿 疑问词
公式要点A 主动↔被动B 只有主动

公式

主动
陈述主语 + did（动词过去式）
否定主语 + didn't + do
一般疑问Did + 主语 + do？
特殊疑问疑问词 + did + 主语 + do？
被动
陈述主语 + was / were + done
否定主语 + wasn't / weren't + done
一般疑问Was / Were + 主语 + done？
特殊疑问疑问词 + was / were + 主语 + done？

do＝动词原形　doing＝现在分词　done＝过去分词　疑问词＝when / where / why / how / what …

要点

  • 主动句借 did，后面的动词回原形：✗ Did they built it?　✓ Did they build it?
  • 被动句有 was / were，不借 did：✗ Did the bridge built?　✓ Was the bridge built?
  • 问主语不倒装，也不借 did：Who wrote this book?（✗ Who did write this book?）

A · 主动 ↔ 被动12 组

同一件事说两遍：先让做事的人当主语（主动），再让被做的东西当主语（被动）。每边四句：陈述 → 否定 → 一般疑问 → 特殊疑问。

A01writewrote · written写
主动
陈述
Lu Xun wrote this book.
鲁迅写了这本书。
否定
Lu Xun didn't write this book.
一般疑问
Did Lu Xun write this book?
Yes, he did. / No, he didn't.
特殊疑问
Who wrote this book?
谁写了这本书？
被动
陈述
This book was written by Lu Xun.
这本书是鲁迅写的。
否定
This book wasn't written by Lu Xun.
一般疑问
Was this book written by Lu Xun?
Yes, it was. / No, it wasn't.
特殊疑问
Who was this book written by?
这本书是谁写的？
