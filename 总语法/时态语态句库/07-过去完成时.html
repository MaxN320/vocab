过去完成时

过去的过去——先立一个过去的时间点，再讲它之前已经完成的事。

看讲解：时态篇 07 →语态篇 →
信号词by + 过去时间 · before / when + 过去时 · by the time … · already
橙 谓语第一个词：扛时间，否定加 not、疑问提前都靠它蓝 时态的其余部分紫 被动：be + done绿 疑问词
公式要点A 主动↔被动B 只有主动

公式

主动
陈述主语 + had + done
否定主语 + hadn't + done
一般疑问Had + 主语 + done？
特殊疑问疑问词 + had + 主语 + done？
被动
陈述主语 + had + been done
否定主语 + hadn't + been done
一般疑问Had + 主语 + been done？
特殊疑问疑问词 + had + 主语 + been done？

do＝动词原形　doing＝现在分词　done＝过去分词　疑问词＝when / where / why / how / what …

要点

  • 过去完成时一定要有一个过去的参照点（when we arrived、by six o'clock、before …），比它更早发生的才用 had done。
  • by 是「到那一刻为止」：By six o'clock, the work had been finished.

A · 主动 ↔ 被动8 组

同一件事说两遍：先让做事的人当主语（主动），再让被做的东西当主语（被动）。每边四句：陈述 → 否定 → 一般疑问 → 特殊疑问。

A01sellsold · sold卖
主动
陈述
They had already sold the tickets when we arrived.
我们到的时候，他们已经把票卖完了。
否定
They hadn't sold the tickets yet when we arrived.
一般疑问
Had they already sold the tickets when you arrived?
Yes, they had. / No, they hadn't.
特殊疑问
How many tickets had they sold when you arrived?
你们到的时候，他们已经卖了多少张票？
被动
陈述
The tickets had already been sold when we arrived.
我们到的时候，票已经卖完了。
否定
The tickets hadn't been sold yet when we arrived.
一般疑问
Had the tickets already been sold when you arrived?
Yes, they had. / No, they hadn't.
特殊疑问
How many tickets had been sold when you arrived?
你们到的时候，已经卖出了多少张票？
