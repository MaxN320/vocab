时态语态句库 · 17

不定式

to do 也分主动被动、也分早晚：to do / to be done / to have done；情态动词后面去掉 to。

看讲解：非谓语动词（重做版）→情态篇 →
橙 谓语第一个词：扛时间，否定加 not、疑问提前都靠它蓝 时态的其余部分紫 被动：be + done绿 疑问词
公式要点A 主动↔被动B 高频 to do 句

公式

主动　／　被动
一般式to do　／　to be done　和谓语同时，或者在它之后
进行式to be doing　／　—　那时正在做
完成式to have done　／　to have been done　比谓语更早
情态动词后can do · must have done　／　can be done · should have been done　去掉 to

不定式自己不带时间：「同时 / 之后」用 to do，「更早」用 to have done；「被做」就在里面加 be + done。

要点

  • 主语自己做，用主动 to do；主语是被做的，用被动 to be done：I want to help.（我想帮忙）／ I want to be helped.（我想有人帮我）
  • 否定、疑问还是靠谓语里第一个词：The roof doesn't need to be fixed.　Does the roof need to be fixed?
  • 推测过去：肯定用 must have done，否定用 can't have done，疑问用 Could … have done?
  • 形容词 + to do 用主动：The question is easy to answer.（✗ easy to be answered）

A · 主动 ↔ 被动10 组

have to / need to / can / should 后面跟主动的 do，还是被动的 be done——主语是做事的人还是被做的东西，决定选哪个。

A01have to +finishfinished · finished完成
主动
陈述
We have to finish the report today.
我们今天得把报告写完。
否定
We don't have to finish the report today.
一般疑问
Do we have to finish the report today?
Yes, we do. / No, we don't.
特殊疑问
When do we have to finish the report?
我们什么时候得把报告写完？
被动
陈述
The report has to be finished today.
报告今天必须完成。
否定
The report doesn't have to be finished today.
一般疑问
Does the report have to be finished today?
Yes, it does. / No, it doesn't.
特殊疑问
When does the report have to be finished?
报告什么时候必须完成？

A10must have done +taketook · taken拿走
推测过去：肯定 must have done，否定换成 can't have done，疑问换成 could have done。
主动
陈述
Tom must have taken my umbrella.
肯定是汤姆拿了我的伞。
否定
Tom can't have taken my umbrella.
一般疑问
Could Tom have taken my umbrella?
特殊疑问
Who could have taken my umbrella?
会是谁拿了我的伞？
被动
陈述
My umbrella must have been taken.
我的伞肯定是被人拿走了。
否定
My umbrella can't have been taken.
一般疑问
Could my umbrella have been taken?
特殊疑问
When could my umbrella have been taken?
我的伞会是什么时候被拿走的？

B · 高频 to do 句

想要 / 打算 + to do：主动、被动

I want to go home.
我想回家。
I don't want to be disturbed.
我不想被打扰。
She hopes to win.
她希望能赢。
She hopes to be chosen.
她希望被选上。
He decided to leave.
他决定离开。
He asked to be moved to another room.
他要求换到别的房间。
Nobody likes to be laughed at.
没人喜欢被嘲笑。
What do you want to do this weekend?
你这周末想干什么？
Do you want to be a teacher?
你想当老师吗？

疑问词 + to do

I don't know what to do.
我不知道该怎么办。
Can you tell me how to get there?
你能告诉我怎么去那儿吗？
She didn't know where to go.
她不知道该去哪儿。
We need to decide when to leave.
我们得决定什么时候走。

seem to 的四种样子

He seems to know the answer.
他好像知道答案。（同时）
She seems to be sleeping.
她好像在睡觉。（正在）
He seems to have forgotten my name.
他好像把我的名字忘了。（更早）
The window seems to have been broken.
窗户好像被人打破了。（更早 + 被动）
Does he seem to know the answer?
他看起来知道答案吗？

其他高频

There is a lot of work to do.
有很多活要干。
There is a lot of work to be done.
有很多活要干。（这两种都对）
This question is easy to answer.
这个问题好回答。（✗ easy to be answered）
I went to the hospital to see a doctor.
我去医院看病。（目的）
He was the first to arrive.
他是第一个到的。
I am sorry to have kept you waiting.
抱歉让你久等了。
He told me not to go.
他叫我别去。（not 放在 to 前面）
It is too cold to go out.
太冷了，出不去。
