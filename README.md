# 📖 英语语法

学英语时整理的语法笔记和测验。

**网站：<https://maxn320.github.io/vocab/>**（手机直接打开，分「语法笔记」「测验」「对照检查」三页）

## 文件夹

| 文件夹 | 放的是什么 |
|---|---|
| `总语法/` | 语法笔记，和本地 OneDrive 的「总语法」文件夹一一对应：基础、词性、时态、从句、语态、情态 |
| `quiz/` | 测验，每套一个网页；做完自动回传结果 |
| `check/` | 课程笔记对照检查：贴上自己的理解和原文文稿提交，检查结果每次一个网页（原文全文不放上来） |
| `tts/` | 生词本、词组列表里例句的朗读音频，自动生成；手机上的 Obsidian 发音插件会从这里在线播放，路径别改 |
| `index.html` | 网站首页 |

笔记以本地 OneDrive 为准，改完再同步到这里。
