# 📖 英语语法

学英语时整理的语法笔记和短文练习。

**网站：<https://maxn320.github.io/vocab/>**（手机直接打开，分「语法笔记」「短文」「每日打怪」三个模块）

## 文件夹

| 文件夹 | 放的是什么 |
|---|---|
| `总语法/` | 语法笔记，和本地 OneDrive 的「总语法」文件夹一一对应：基础、词性、时态、从句、语态、情态 |
| `passage/` | 按大纲分组的短文和造句练习 |
| `daily/` | 「每日打怪」的每日练习，第一天为 `Day01.html` |
| `tts/` | 共用朗读音频；手机上的 Obsidian 发音插件会从这里在线播放，路径别改 |
| `index.html` | 网站首页 |

笔记以本地 OneDrive 为准，改完再同步到这里。
